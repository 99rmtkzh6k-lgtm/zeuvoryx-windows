# Comparative laboratory protocol — 25 November 2026
References: https://www.av-test.org/en/about-the-institute/test-procedures/ ; https://av-comparatives.org/real-world-protection-test-methodology/ ; https://www.amtso.org/standards/
This is an internal diagnostic inspired by the three axes, not an AV-TEST/AV-Comparatives certification. Production source scanner.go and pe.go unchanged, isolated branch. Previous public metadata run 45647629757 passed both platforms.
Protection: existing public IOC checks plus harmless complete-file and ZIP digest matches, cancellation and JSON. Usability: 600 generated benign files per cycle, including documentation of security terminology; count advisory alerts separately from blocking, which is not measured. Performance: compare read+SHA256 baseline with actual scanner on 128 generated files; fixed workload, report bytes/time, not whole-system impact. Five repetitions per OS. No malware, no real ransomware execution, no claim of representative false-positive rate. A positive test with injected known digest is not detection of an unknown threat. Results are observational; failed/incomplete coverage invalidates a cycle. No numeric independent rating until representative live malware testing, normal workloads and product installation tested. No production changes or release. Keep test definitions fixed before adjusting motor; after fixes use new holdout corpus.

## Evolution after run 45647991167

It also hashes complete files in one sequential pass and retains bounded sample, avoiding second read. Regression covers file sizes smaller/larger than sample, empty files, evidence and existing remediation policy. Lab only: not the generated installer; integration, UI consumption, new performance comparison and physical Windows acceptance pending. Alert frequency is not claimed reduced.
