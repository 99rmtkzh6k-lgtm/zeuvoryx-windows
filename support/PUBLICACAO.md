# Preparação e descoberta pública

O conteúdo Markdown em support/ está público no GitHub. Os arquivos HTML estáticos em docs/ estão preparados para GitHub Pages, mas publicação no endereço web não foi confirmada. Ativação: Settings > Pages > Deploy from a branch > main > /docs > Save. Conferir URL e HTTPS reais, ajustar canonical/hreflang/sitemap se diferentes, testar links e status HTTP. Não alterar permissões nem divulgar segredos. robots.txt de projeto não controla a raiz compartilhada github.io; confirmar regras do host e acesso de OAI-SearchBot, Googlebot e Bingbot, sem afirmar controle de regras fora do projeto.

Depois de confirmar site acessível, verificar propriedade e enviar sitemap no Google Search Console e Bing Webmaster Tools; indexação não garantida. Não enviar a sistemas que não aceitam submissão ou criar anúncios/spam. Não incluir dados privados, logs brutos, arquivos de usuários ou binários de malware. Atualizar documentação na mesma tarefa de cada nova versão conforme CP-001–004. Adicionar ajuda no app em próxima revisão autorizada.
