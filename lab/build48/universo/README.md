# UNIVERSO BOTELHO

Um projeto com dois jogos, 20 fases e recursos offline. (One project with two games, 20 stages and offline assets.)

- Jogo 1 / Game 1: Família Botelho vs Horda Zumbi (2035).
- Jogo 2 / Game 2: Robozinho Botelho Recicla (2100).
- HTML, CSS, JavaScript puro / Vanilla HTML, CSS, JavaScript; Web Audio API; emoji; sem dependências / no dependencies.
- Botecoin e cupons fictícios / Fictional currency and coupons.
- Vozes faladas dependem das vozes locais do dispositivo; falas escritas bilíngues sempre disponíveis. / Spoken voices depend on local device voices; bilingual written dialogue is always available.
- Salve no navegador ou copie o código de salvamento. / Save in your browser or copy the save code.
- Fase 9 do Jogo 1: cinco ondas com 30 inimigos no total. / Five waves with 30 enemies total.
- Jogo 2: primeira viagem resgata a família; viagens seguintes resgatam pessoas anônimas em grupos de cinco. / First trip rescues the family; later trips rescue unnamed groups of five.

## Publicação / Publishing
1. Crie o repositório `universo-botelho` / Create the repository.
2. Envie index.html, style.css, script.js e README.md à raiz da main / Upload all four files to the main branch root.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Abra o endereço fornecido pelo GitHub Pages / Open the URL shown by GitHub Pages.

Para executar localmente, mantenha os três arquivos web na mesma pasta e abra index.html no Chrome. / To run locally, keep the three web files together and open index.html in Chrome.
