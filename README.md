# ZEUVORYX Macintosh 3.0.5 LAB — candidato

Scanner complementar experimental somente leitura para macOS 13+, Intel e Apple Silicon. Swift/SwiftUI e Go. Created & Engineered by Leonardo A Botelho.

**Candidato não aprovado para distribuição:** evolução da 3.0.3 LAB com análise estrutural de links local, sem acesso à rede, regressões herdadas do Windows R5, comando de versão e gate de identidade do pacote. Não implica paridade funcional integral com Windows.

[Compilações Macintosh](https://github.com/99rmtkzh6k-lgtm/zeuvoryx-windows/actions/workflows/macintosh-build.yml) — selecionar `macintosh-3.0.5-lab`. Somente baixar artefatos depois de aprovação para a arquitetura correspondente. A versão anterior [3.0.3 LAB](https://github.com/99rmtkzh6k-lgtm/zeuvoryx-windows/tree/macintosh-3.0.3-lab) permanece preservada.

## Limites
Scanner local, SHA-256, EICAR de teste, alerta de extensão dupla, diagnósticos e análise consultiva de URL. Sem remoção, quarentena, proteção residente, telemetria, atualizador real ou IA integrada ao scanner. Não desativar Gatekeeper, XProtect ou proteções existentes. Assinatura ad hoc, sem Developer ID/notarização. Testes de eficácia, UI nativa e computadores reais pendentes. Idiomas principais pt/en/es; detalhes técnicos do analisador de links permanecem em português. Consulte [memorando Macintosh](MEMORANDO_MACINTOSH.md) e [memorando central](https://github.com/99rmtkzh6k-lgtm/zeuvoryx-windows/blob/main/MEMORANDO_DESENVOLVIMENTO.md).
