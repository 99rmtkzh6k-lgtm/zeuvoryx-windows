ZEUVORYX Antivirus — ヘルプセンター

ZEUVORYX Windows 3.0.6 LAB R1 の公開サポート情報です。実験段階の補助的なセキュリティソフトウェアであり、製品版、第三者認証、Microsoft Defender の代替を意味しません。

ZEUVORYX とは？

Go で開発された Windows x64 向けセキュリティスキャナーです。ファイル分析、SHA-256 指標、ヒューリスティック分析、復元可能な隔離、実験的な補助 AI を備えています。Macintosh 3.0.5 LAB は別の検証中の候補版です。

インストールと更新

管理者が許可したテストパッケージのみを使用し、GitHub の参照情報でバージョンと SHA-256 を確認してください。ZIP を展開し、スキャンを終了または中止してアプリを閉じ、設定と隔離データをバックアップしてから互換性のある LAB 版に上書きインストールしてください。Defender、SmartScreen などの保護機能は無効にしないでください。CI で 3.0.5 LAB から 3.0.6 LAB への更新を確認しましたが、他の移行は未検証です。

起動しない、または突然終了する場合

再インストールを繰り返さず、バージョン、Windows x64、Microsoft Edge WebView2 Runtime、空き容量とメモリを確認してください。信頼性モニター（perfmon /rel）とイベントビューアー（eventvwr.msc）のアプリケーション／システムログを障害時刻の前後で確認します。隔離データを削除したり Windows の保護機能を無効にしたりしないでください。サポートには匿名化した情報だけを共有してください。

フルスキャンが停止・終了する場合

実機での突然の終了は調査中です。3.0.6 の CI では起動確認後に画面が15秒間開いていることを確認し、小規模な管理されたファイル群のスキャンテストが60回成功しました。ディスク全体の安定性を証明するものではありません。再発した場合は業務用 PC でのテストを中止し、時刻、バージョン、スキャンモード、CPU/RAM 使用状況、最後の進捗を記録してください。不審なファイルは実行しないでください。

エラー、スキップ、警告

アクセス拒否、他のプロセスによるロック、ファイルの消失により読み取れない場合があります。部分的なレポートや検出数ゼロは安全性の証明ではありません。ヒューリスティックや AI スコアは参考情報であり、マルウェアの確定ではありません。警告だけを理由にシステムファイルを削除しないでください。

AI、リアルタイム保護、ClamAV、更新

現行 AI は補助的な分析を行い、継続的なローカル学習は未検証です。独自の常駐保護、継続学習、製品版の自動更新、世界統計は開発中です。ClamAV は別途インストールが必要な任意機能です。自己診断の成功は世界規模のサービス稼働を意味しません。製品版の公開は未発表です。

サポートへの問い合わせ

GitHub Issues にバージョン、Windows 10/11 のビルド、アーキテクチャ、おおよその RAM、スキャンモード、時刻とタイムゾーン、期待した結果と実際の結果、再現手順、可能であればエラー分類や終了コードを記載してください。氏名、個人のパス、メール、トークン、識別子、ファイル内容、非公開ファイルのハッシュは削除してください。マルウェアのサンプル、生ログ、隔離ファイル、認証情報は投稿しないでください。24時間の対応は保証されません。
