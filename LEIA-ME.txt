ZEUVORYX 3.0.1 | OLYMPUS — Competitive Beta
24/11/2026

Atualização cumulativa da versão experimental 3.0.1. Substitui o script
zeuvoryx_upgrade.py anterior; não execute as duas versões em sequência.
Não é instalador, executável ou certificação de proteção.

INSTALAÇÃO NO GITHUB (preserve main)
1. Crie uma branch a partir de main chamada zeuvoryx-3.0.1-competitive.
2. Extraia este ZIP. Envie SOMENTE zeuvoryx_upgrade.py à raiz da branch.
3. Na mesma branch, edite .github/workflows/windows-build.yml.
   Imediatamente antes da linha "      - name: Validate source code",
   cole o conteúdo de PASSO-WORKFLOW.txt, preservando os espaços.
   Se já existir a etapa "Apply ZEUVORYX 3.0.1 scanner hardening", não a duplique.
4. Confirme as alterações nessa branch. Em Actions, selecione o workflow
   Windows, clique em Run workflow e selecione a branch experimental.
   O push na branch não dispara automaticamente o workflow atual.
5. Só baixe os artefatos do run experimental se todos os testes e build
   terminarem com sucesso. Não faça merge em main antes do teste na VM.
6. No Windows virtual, mantenha o Defender ativo. Teste análise rápida e
   completa, alertas, filtros e relatório. Não coloque arquivos de sistema
   em quarentena. Exporte o JSON e o diagnóstico de testes.

ALTERNATIVA COM CÓPIA LOCAL DO REPOSITÓRIO
Na raiz da cópia da branch, após copiar zeuvoryx_upgrade.py, rode:
  python zeuvoryx_upgrade.py --install
Isso insere a etapa no workflow (não gera o EXE). Revise o diff antes do commit.
Não envie o arquivo de backup .bak. O --apply é reservado à etapa do CI
após a geração de código do workflow existente.
